# Changelog

## 0.2.0 — 2026-10-16

First playable sandbox:

- Deterministic sand, water, walls, and sand/water displacement.
- Colored terminal rendering, cursor movement, circular brushes, and continuous spray.
- Pause, single-step, clear, demo reload, eraser, and compact help.
- Resize-safe viewport and terminal restoration on normal exit, exceptions, and supported signals.
- Headless snapshots, strict CLI validation, physics benchmarks, and cached row redraws.
- Native and pseudo-terminal tests, measured performance, and a real demo recording.

## 0.1.0 — 2026-10-16

Initial structured workspace, pinned local tools, build presets, smoke tests,
contributor workflow, and GitHub Actions.
