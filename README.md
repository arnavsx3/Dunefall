# Dunefall

A tiny world of sand, water, and beautiful chaos.

Dunefall is a terminal physics playground written in C++. Sprinkle particles, build walls, and watch your miniature world come alive.

## Planned features

- **Sand** that falls, settles, and forms piles.
- **Water** that flows through gaps and around obstacles.
- **Walls** for building dams, containers, and questionable experiments.
- **Colored particles** for a retro terminal feel.
- **Keyboard controls** to paint, switch materials, and reset the world.

## Built with

C++ — handling the simulation, rendering, and input.

## Status

Under development. Build instructions and controls will be added with the first playable version.
